## Contract and limits

The clean-room implementation follows [T.81](https://www.w3.org/Graphics/JPEG/itu-t81.pdf),
particularly A.2 for sampling/MCU order, B.2 for marker fields, C.2 for
Huffman codes, and H for lossless differences and restart-row constraints.
Independent contract review preceded implementation review; no reference
decoder implementation was consulted.

Validation consumes entropy without allocating output pixels. Each lossless
data unit is one sample. Interleaved scans include H*V units per component per
MCU, including edge padding; a single-component scan has one unit per MCU.
Restart counts use MCU rows, not output pixel rows or component samples.
Category16 has no amplitude bits. Larger-than-precision categories can be
legal with predictor4, so sample precision alone cannot bound categories.

This work checks Huffman syntax, expected unit counts, padding, restart
boundaries and the parsed end of the stream. It does not reconstruct samples,
demosaic, or establish that the decoded picture matches the original scene.
Legal amplitude changes may produce another valid image. DNL, separated
component scans and frames with more than four components remain unsupported.
Pixel decoding retains its prior component/sampling restrictions.

Finding offsets are relative to the supplied JPEG payload. Entropy findings
identify the detection cursor, which may be after the changed byte due to
lookahead or desynchronization; they are not advertised as exact mutation
locations. The existing trailing-data-after-EOI finding is informational:
container-level extent policy belongs to the caller.

## Verification record

The first facade regression failed with expected valid, found unsupported.
An earlier attempt placed it in the legacy oracle test target, which lacks
Brotli linkage for validateAny; that linker failure was not a behavioral red.
The test moved to the existing facade target, with no build-system changes.

`./test` passed the complete suite, including 52 CLI assertions, 71 C-FFI
assertions and three zero-C consumer controls. `./build`, Windows cross-build
and validator-closure checks passed. A final comment-only source edit produced
the same executable hash as the binary from the full suite's package check.

Independent static review approved the scoped entropy path after regressions
covered legal DNL with zero/redefined height and marker fill, reversed SOS
component order, and standalone markers incorrectly treated as length-prefixed
unsupported segments. The padded standalone-marker regression failed with
expected corrupt, found unsupported before the guard. The unused-DQT control
also failed before preserving the pixel decoder's prior skip behavior.
The review did not certify reconstructed sample semantics or run runtime gates.
